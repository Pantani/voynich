Rota 42G

Ferramentas ativas

Esta e a entrada unica do fluxo atual. As ferramentas antigas foram removidas da pasta de paginas para nao confundir a revisao humana.

Novo modo facil: use a R42K para escolher o alvo, a R42L para confirmar a sugestao, a R42M para conferir a captura fina, e depois aplique na R42F.
R42G - Painel unico Comecar aqui e navegar sem se perder. Abra a R42K para escolher o proximo alvo com menos atrito. R42K - Fila priorizada Ordenar as pendencias da R42F usando os fragmentos visuais da R42J. Abra a R42L para confirmar a sugestao antes de mexer na R42F. R42L - Confirmar sugestao Confirmar ou rejeitar a linha sugerida pela fila, com recortes e alternativas lado a lado. Abra a R42M para conferir a captura fina antes de aplicar na R42F. R42M - Captura fina Alinhar recortes mais estreitos usando a uniao dos fragmentos visuais. Use como lupa; confirme a decisao na R42L/R42F. R42F - Escolher linha visual Escolher a linha correta vendo recortes reais da pagina, sem precisar ler codigo EVA. Clique no recorte que bate, depois copie/baixe o CSV. R42D - Sugestoes OpenCV Transformar escolhas de linha e zonas pequenas em sugestoes pendentes para conferir. Reexecute depois de preencher a R42F. R42J - Fragmentos visuais Fazer uma analise mais fina por computer vision dentro de cada linha visual. Use como lupa de fragmentos, depois volte para R42F ou R42C. R42C - Calibrar linha fina Ajustar a linha real com dois pontos e conferir pela lupa de recorte. Confirme ou ajuste a baseline antes de usar na revisao final. R42B - Preencher revisao R32 Fazer a decisao final olhando primeiro os recortes reais da pagina. Use depois que as linhas estiverem mais faceis de localizar. R42E - Mapa de linhas OpenCV Auditar as linhas visuais detectadas pela maquina quando algo parecer estranho. Use como apoio, nao como decisao final.

Ordem simples

  1. R42K: pegar o proximo alvo mais facil da fila.
  2. R42L: confirmar se a linha sugerida realmente bate.
  3. R42M: conferir a captura fina gerada pelos fragmentos.
  4. R42F: aplicar a escolha de linha visual correta.
  5. R42D: deixar o OpenCV transformar isso em sugestao pendente.
  6. R42J: usar fragmentos visuais como lupa quando a linha ainda estiver dificil.
  7. R42C: confirmar ou ajustar a linha fina.
  8. R42B: fazer a revisao humana final.
