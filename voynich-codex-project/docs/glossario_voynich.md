# Glossário mínimo

- **EVA**: European Voynich Alphabet, convenção de transliteração gráfica.
- **IVTFF**: formato interlinear de transcrição que marca folio, locus e variantes.
- **Locus**: unidade textual/visual, como parágrafo, rótulo, círculo ou raio.
- **Currier A/B**: regimes estatísticos identificados por Prescott Currier.
- **Gallows**: glifos altos frequentemente transliterados como `k`, `t`, `p`, `f` em EVA.
- **Rótulo**: palavra isolada junto a desenho, estrela, recipiente, figura etc.
- **Rubrica**: camada destacada por cor/posição, como o vermelho de f67r2.
- **Template**: padrão recorrente de formação de token.
- **Borda**: caractere/grupo no início ou fim do token com possível função estrutural.
