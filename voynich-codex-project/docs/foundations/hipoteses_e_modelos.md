# Hipóteses e modelos de trabalho

## Modelo principal: sistema formal em camadas

O Voynichese pode ser entendido como um sistema onde cada token recebe valor a partir de:

1. seção do manuscrito;
2. tipo de locus: texto corrido, rótulo, círculo, raio, rubrica;
3. posição física: início/meio/fim de linha;
4. operador de entrada: `qo-`, `o-`, `ok-`, `ot-`, `yk-`, `yt-`;
5. núcleo/template;
6. valor de borda: `-dy`, `-y`, `-ar`, `-al`, `-or`, `-ol`, `-aiin`.

## Hipótese A — cifra homofônica/verbosa

Ainda possível, mas precisa explicar:

- efeito de linha;
- diferenças de locus;
- alta regularidade interna dos tokens;
- rótulos com distribuição própria.

## Hipótese B — notação técnica artificial

Forte. Explica bem:

- rótulos diferentes do texto corrido;
- diagramas em camadas;
- operadores repetidos;
- matriz `ar/al/or/ol`.

## Hipótese C — texto natural muito transformado

Forte, desde que inclua:

- abreviações;
- operadores;
- dependência de layout;
- possível inversão funcional de borda.

## Hipótese D — texto gerado por regras

Possível. Porém o gerador teria que reproduzir:

- tópicos por seção;
- correlações visuais;
- Currier A/B;
- subgramática de rótulos;
- efeito de linha.

## Hipóteses enfraquecidas

| Hipótese | Por que enfraqueceu |
|---|---|
| substituição simples | não explica linha/locus/bordas |
| língua europeia direta | não explica previsibilidade interna extrema |
| rótulos como nomes diretos | formas atravessam contextos visuais demais |
| `okal = Sol` | família aparece em contextos demais |
| ruído aleatório | padrões por seção e locus são fortes demais |
